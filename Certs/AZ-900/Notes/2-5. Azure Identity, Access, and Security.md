# **AZ-900 Notes: Domain 2 - Azure Services**

## **Azure Identity, Access, and Security**

### **Entra ID**

Entra ID is Microsoft's cloud-based identity and access management service that authenticates and authorizes users, and it is inherently a part of every Azure subscription. Entra ID ensures that the correct person is signing in to the account *and* that they have the correct permissions to access the resources they are trying to access. Entra ID can also use **service principals** to allow applications to access resources without a user being present. Entra ID is used for **single sign-on (SSO)**, which allows users to log in once and access multiple applications without having to log in again. Computers and devices can also be registered with Entra ID to allow for device-based authentication. Entra ID is a critical component of Azure's security model, providing a centralized way to manage user identities and access to resources.
