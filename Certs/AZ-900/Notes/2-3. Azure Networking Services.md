# **AZ-900 Notes: Domain 2 - Azure Services**

## **Azure Networking Services**

### **Azure Virtual Networking**

Virtual networks and subnets enable communication between Azure resources and users / on-prem computers. They provide capabilities like:

- Isolation and segmentation
- Traffic routing and filtering
- Connecting virtual networks, on prem resources, and Azure resources

**Virtual Network Peering** is when two Azure VNets are connected together. Traffic between the two VNets travels on Microsoft's private network, meaning the traffic is does not require VPN-style encryption. VNets can be peered in the same region or in different regions (global virtual network peering).

**Public endpoints** are publicly routable from nearly anywhere in the world. **Private endpoints** only have a private IP address and only exist within a virtual network.

### **Azure DNS**

Azure DNS allows you to manage your DNS records in Azure. Internet-facing zones are called **public zones**, while zones used for Azure VNets are called **private zones**.

### **Azure VPN Gateway**

Azure VPN Gateway is a service that provides secure connections between Azure Vnets and other networks. It uses a **gateway subnet**, inside of which are Microsoft-managed resources that implement and run the VPN Gateway.

There are three types of VPN Gateways:

| VPN Connection Type | Description |
| ---------------- | ----------- |
| **VNet-to-VNet** | Connects two Azure VNets together |
| **Site-to-Site** | Connects an Azure VNet to on-prem network |
| **Point-to-Site** | Connects a single device (phone, computer, etc) to an Azure VNet |

An important note about Azure VPN Gateway: VPN encryption isn't free. Encrypting, decrypting, and encapsulating traffic requires processing resources and adds network overhead.

### **Azure ExpressRoute**

Azure ExpressRoute, like Azure VPN Gateway, allows you to connect on-prem networks to Azure VNets; however, ExpressRoute offers significantly faster speeds over private connections. Instead of traffic flowing over the internet, traffic is flowing over a private connection via a Microsoft Enterprise Edge (MSEE) router. This private connection is called a **circuit**.

**VPN Gateway** = encrypted connectivity, commonly across the public internet\
**ExpressRoute** = private connectivity into Microsoft's network
